# Archived One-Off Scripts

These scripts are retained for reference but are not part of the normal site runtime, import pipeline,
deployment flow, Discord bot, or admin Control Center actions.

They were archived to keep the top-level `scripts/` folder focused on active workflows. If one is
needed again, move it back to `scripts/` first and re-check any imports or command examples inside it.

Archived scripts:

- `_fetch_cap_logos.py` — one-time logo fetch helper.
- `apply_unresolved_team_season_record_mappings.py` — one-time team-season record mapping repair.
- `backfill_bowl_six_scoring_games.py` — historical BOWL Six scoring backfill.
- `convert_wide_all_stars_to_history_csv.py` — legacy all-star sheet converter.
- `diagnose_stats.py` — ad hoc stats diagnostic.
- `export_unresolved_team_season_records.py` — paired export for manual team-season repair.
